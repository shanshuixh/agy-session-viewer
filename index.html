Antigravity 会话

Antigravity 会话查看器

纯本地运行，数据不会离开浏览器。点击下面的按钮，选择 Antigravity / AGY CLI 的数据目录：

C:\Users\<你的用户名>\.gemini（选 .gemini 可自动聚合 IDE 与 CLI；也可单选其下的 antigravity 或 antigravity-cli）

  • 按工程工作区目录独立归类（不论是 Antigravity IDE 还是 AGY CLI，每个工程独立成一个目录）；点击会话后可查看完整记录及关联子代理。
  • 点击会话后，按 UUID 读取 conversations/<UUID>.db 中的 steps 表并解码。
  • 会自动合并 .db-wal 中尚未写回的数据；旧版 .pb 文件是加密的，无法读取。
  • 推荐使用 Chrome / Edge，可记住目录；其他浏览器会退回到文件夹上传方式。
